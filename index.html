경로 고르기

처음이라면 경로부터 고르세요

두 경로 모두 근거 검증은 생략하지 않습니다. 빠른 제작은 승인을 중요한 지점에 묶고, 정밀 제작은 각 산출물을 따로 검토합니다.

경로를 누르면 바로 프롬프트 만들기로 이동해요. 아래 ①~⑨ 설명은 단계를 진행하다 막힐 때 참고하면 돼요.

웹 시안과 실제 PPT는 다릅니다

✓ PowerPoint는 클릭 기반 애니메이션과 Morph를 지원합니다.
✓ Morph는 앞뒤 슬라이드의 객체 이동·크기·위치 변화를 연출합니다.
! 차트는 Morph로 변형되지 않고 교차 페이드됩니다.
! Morph를 만들려면 Microsoft 365·PowerPoint 2019 이상(웹 포함)이 필요합니다. 2016은 재생만 됩니다. 발표장 PC 버전을 확인하세요.
! Gamma의 애니메이션은 AI로 만든 움직이는 이미지(상위 요금제)로, PowerPoint의 클릭 빌드·Morph와는 다른 기능입니다.
! 웹 애니메이션은 PPTX로 자동 변환되지 않습니다.

동작이 핵심이라면 HTML을 발표본으로 쓰거나, PowerPoint에서 애니메이션을 다시 구현하고 검수하세요.

디자인 레퍼런스 첨부

내가 고른 디자인 레퍼런스를 첨부할게: (링크 + 캡처 2~3장)
레퍼런스마다: 가져올 것(색·글꼴·배치·여백·도식 스타일) / 가져오지 않을 것(로고·문구·사진) / 우리 덱에 맞춘 변형을 표로 정리하고, 1번 장과 숫자 장에 적용한 시안을 보여 줘.

모션 레퍼런스 첨부

참고할 움직임을 첨부할게: (영상·CodePen·GitHub 데모 링크 + 구간 + 핵심 프레임 캡처 3~6장)
구간마다 무엇이 · 어느 방향으로 · 어떤 순서·간격·속도로 움직이는지 분석하고, 우리 대본의 어느 문장·어느 요소에 쓸지 대응표를 만든 뒤 한 장에 먼저 적용해 보여 줘. 영상을 직접 볼 수 없으면 캡처와 설명만 근거로 했다고 밝혀 줘.

③ 내가 직접 고칠 수 있게 — 인터랙티브 디자인 프롬프트

덱을 만든 뒤 같은 대화(또는 에이전트)에 하나씩 붙여 넣으세요. 고친 값은 JSON으로 저장되고, "반영해 줘"라고 하면 설계 파일에 되돌아가요.

디자인 조절 패널

덱에 디자인 조절 패널을 추가해 줘. T 키로 열고 닫기.
- 슬라이더·선택: 강조색, 글꼴 쌍(3가지 후보), 제목 크기, 여백, 모션 세기(끄기·약하게·보통·강하게)
- 바꾸면 모든 장에 즉시 반영 (CSS 변수만 바꾸기)
- "이 값 저장"을 누르면 tokens.json으로 내려받기, 그 값을 tokens.css에 반영해 달라고 하면 반영

장별 배치 바꾸기

장마다 배치 변형 2~3개를 만들어 줘. L 키를 누르면 현재 장의 배치가 바뀌고, 화면 구석에 "배치 B/3"처럼 보여 줘.
- 제목·숫자·대본은 그대로, 배치와 도식 종류만 다르게
- 고른 배치는 layout_choice.json으로 저장 → 그 배치로 확정해 달라고 하면 05에 반영

드래그로 위치 옮기기

편집 모드(E)에서 요소를 마우스로 끌어 옮기고 크기를 바꿀 수 있게 해 줘.
- 0.5% 격자에 붙기, 다른 요소와 겹치면 빨간 테두리
- 저장하면 positions.json(data-el → x,y,w,h px) 내려받기 → 05 좌표에 반영

시안 갤러리

같은 장을 서로 다른 방향으로 6개 만들어 한 화면 격자로 보여 줘(잡지 지면 · 스위스 그리드 · 포스터 · 신문 그래픽 · 손그림 노트 · 다크 키노트).
- 각 칸을 누르면 크게 보기, 마음에 드는 칸 2개를 체크하면 두 시안의 요소(색·글꼴·배치)를 섞은 새 시안을 만들어 줘

모션 타임라인 미리보기

현재 장의 움직임을 타임라인으로 보여 줘(M 키).
- 단계별 막대(무엇이 · 언제 · 몇 ms), 재생·일시정지·0.25배속
- 막대를 끌어 시작 시점·길이를 바꾸면 바로 미리보기, 저장하면 motion.json → 06에 반영

레퍼런스에서 스타일 뽑기

첨부한 레퍼런스 캡처(또는 링크)에서 색 4~6개(HEX), 글꼴 느낌, 여백 리듬, 모션 성격을 뽑아 tokens 후보 3개를 만들어 줘.
- 후보마다 우리 1번 장에 적용한 미리보기를 나란히
- 레퍼런스의 로고·문구·그림은 가져오지 말고 스타일만

리허설 모드

R 키로 리허설 모드를 켜 줘: 장별 목표 시간(대본 길이로 계산)과 실제 경과 시간, 다음 장 첫 문장, 남은 시간을 보여 주고, 목표보다 20% 넘으면 표시가 빨개지게. 끝나면 장별 시간 기록을 rehearsal.csv로 저장.

청중 반응 장

마지막 장에 청중이 직접 참여하는 인터랙티브 요소를 넣어 줘: 3개 선택지를 누르면 막대가 자라는 즉석 투표(화면 안에서만 동작), 또는 "나의 원칙" 빈칸에 직접 입력하면 카드로 쌓이기. 인터넷 없이 동작하게.
